# ASCII RPG

Otwarty świat RPG renderowany znakami. Canvas 2D, TypeScript, zero zależności runtime.

- Kontrakt pracy: `CLAUDE.md`
- Architektura: `docs/architektura.md`
- Zadania: `docs/zadania/`
- Prototyp dowodzący koncepcji: `docs/prototyp/ascii-city.html` (otwórz w przeglądarce)

pnpm install
